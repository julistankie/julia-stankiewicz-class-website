This page was made with css grid layout. I was able to set all grid boxes inside a container. The interactive element was achieved by query, event listener, and 'clicked' event that I asked chatGPT to help me with. The script is as follows:

            document.querySelector(".container").addEventListener("click", (event) => {
                if (event.target.matches(".container > div")) {
                    event.target.classList.add("clicked");
                }
            });

When a user clicks on a grid box, the 'clicked' class is added to that box, which changes its background color to reveal the sunset image.

            .container > div.seven.clicked {
                background-color: #ffcc80;
                border-color: orange;
                color: orange;
            }

When all 10 boxes are clicked, the sunset image is fully revealed. Refresh the page to play again.
